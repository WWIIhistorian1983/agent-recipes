Auto-booking replies for interested prospects

💼 Salescost: lowdifficulty: medium

Problem

Back-and-forth scheduling slows deals.

Tools

  • Gmail
  • Make
  • OpenAI API
  • Calendly

Setup steps

  1. Watch a Gmail label for replies
  2. Classify intent (interested / not now / unsubscribe) with the OpenAI API
  3. For 'interested', draft a reply with your Calendly link
  4. Keep a human approval step before sending
