Draft replies for the support inbox

supportcost: lowdifficulty: medium

Problem

Small teams spend hours writing similar replies.

Tools

  • Gmail
  • n8n
  • Anthropic API

Setup steps

  1. Self-host or use n8n cloud; add a Gmail trigger
  2. Retrieve relevant docs snippets and pass with the email to the Anthropic API
  3. Save the result as a Gmail draft, never auto-send
  4. Track edit rate to improve the prompt
